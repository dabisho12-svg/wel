STUDENTS ON ANY DEVICE - SETUP (about 5 minutes, done once)
===========================================================
Files in this folder: index.html, style.css, app.js, config.js, setup.sql

1. Go to supabase.com, sign up (free) and click "New project".
2. In the project, open "SQL Editor", paste everything from setup.sql, click Run.
3. Open "Project Settings" > "API". Copy the Project URL and the anon public key.
4. Open config.js in Notepad. Paste them between the quotes:
      window.SB_URL = 'https://abcdxyz.supabase.co';
      window.SB_KEY = 'eyJ...your key...';
   Save the file.
5. On github.com open your repository > Add file > Upload files. Drag in ALL FIVE
   files (index.html, style.css, app.js, config.js, setup.sql), then Commit changes.
   Settings > Pages > main branch, / (root).
6. Open the GitHub link. The login box must say "Shared database: ON".
7. First login: admin / admin123. Change the password, then create the accounts.

If the login box says OFF: config.js is empty or was not uploaded.
"Server error 401/403": setup.sql was not run, or the key is wrong.
"Server error 404": the table kv does not exist: run setup.sql.

NOTE: passwords are stored as plain text and the key is visible in the page, so this
is for a trial. Ask for the secure server version before real exams.
